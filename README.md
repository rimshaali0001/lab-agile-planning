# Agile Planning Lab (SE)

This was a lab task for my Software Engineering course where we had to 
learn how Scrum/Kanban actually works by using GitHub's own tools instead 
of Trello or Jira.

I created issues for the backlog items (like "User story: Create login page", 
"Design homepage UI" etc.) and used a GitHub Project board to move them 
through stages: Backlog -> Ready -> In Progress -> In Review -> Done.

Check the Issues tab for the actual backlog items, and the screenshots 
folder for how the board looked.

Honestly this was more about understanding the Agile process than writing 
code, so there's no actual software here - just the planning/tracking part.
